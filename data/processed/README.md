# Processed Data

`data/processed/` には、正式な実験で利用する再生成可能な加工済みデータを保存します。

Processed dataは、raw data・source code・experiment configから再生成できる状態を維持してください。文書化されていない手作業だけで生成したデータを正式なexperimentで使用しないでください。

主要なprocessed datasetを追加した場合は、このREADMEに以下を記録します。

* dataset名と目的
* source data
* 生成コマンドまたは生成方法
* 主な変換
* 利用上の注意点

現在、登録済みのprocessed datasetはありません。
