# Experiment Queue

このfileはactiveなhypothesis proposalの**短いindex**です。上から順に自動実行しません。

詳細なproposalが必要な場合は `docs/templates/experiment_job.md` を使って同directoryにjob fileを作成してください。

| Job | Status | Priority | Search Branch | Hypothesis |
| --- | --- | --- | --- | --- |
| - | - | - | - | まだjobなし |

意味のあるexperiment結果が出た後は、`docs/STATUS.md` のSearch Mapと合わせてqueueを再評価します。
